## 2024-05-18 - Fix TriStateCheckbox accessibility and state initialization
**Learning:** For custom tri-state checkboxes, explicitly setting `aria-checked="mixed"` is required when in the mixed state, as screen readers will otherwise announce them incorrectly as 'unchecked' if backed by a standard boolean property or omitted. Furthermore, when extending UI component classes that invoke lifecycle methods like `applyStyles()` within their constructor, TypeScript parameter properties (e.g., `private _state`) are initialized after the `super()` call.
**Action:** Overridden methods in subclasses must handle cases where these parameter properties are initially `undefined` or use conditions correctly avoiding overriding state. Ensure `aria-checked="mixed"` is used properly for tri-state components.
