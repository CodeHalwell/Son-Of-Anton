## 2024-06-25 - Tri-State Checkboxes and TypeScript Parameter Properties
**Learning:** When using tri-state checkboxes in custom UI components, explicitly setting `aria-checked="mixed"` is required because screen readers will incorrectly announce it as 'unchecked' if backed solely by a boolean structure or left unset. Additionally, when overriding lifecycle methods like `applyStyles` that are invoked from a base class constructor via `super()`, subclass parameter properties (like `private _state`) are evaluated as `undefined` at that moment.
**Action:** When a mixed state is expected on load, explicitly set `aria-checked="mixed"` immediately after the `super()` call, since `applyStyles` triggered during `super()` won't have access to the correct state yet. Update `applyStyles` to properly toggle between 'true', 'false', and 'mixed' dynamically.
