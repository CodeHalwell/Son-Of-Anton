## 2026-10-24 - TriState Checkbox aria-checked\n**Learning:** For custom tri-state checkboxes, explicitly setting `aria-checked="mixed"` when in the mixed state is crucial for screen readers to announce them correctly, as they otherwise might be announced incorrectly if backed by a standard boolean property.\n**Action:** Set `aria-checked` on the underlying DOM element inside `TriStateCheckbox` when state is 'mixed'.
