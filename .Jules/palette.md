## 2024-05-18 - Tri-State Checkbox Accessibility
**Learning:** For custom tri-state checkboxes in this app's component system, explicitly set `aria-checked="mixed"` when in the mixed state. Otherwise, screen readers will incorrectly announce them as "unchecked" if they are backed by a standard boolean property in the DOM. Also, when extending UI component classes that invoke lifecycle methods within their constructor, note that TypeScript parameter properties are initialized *after* the `super()` call, meaning overridden methods must handle cases where these properties are initially `undefined` or initialized explicitly.
**Action:** When creating or modifying tri-state checkboxes, ensure `aria-checked` is explicitly set to `"mixed"` during state updates and verify proper initialization order in component constructors.
