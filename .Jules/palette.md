## 2024-05-24 - TriStateCheckbox Mixed State Screen Reader Issue
**Learning:** In the `TriStateCheckbox` component, when the state was `'mixed'`, the underlying toggle DOM node correctly displayed a "dash" icon but it wasn't updating `aria-checked` accurately. It was likely defaulting to screen readers announcing it as unchecked. A standard boolean checkbox sets it to `'true'` or `'false'`. For a tri-state checkbox backed by a `boolean | 'mixed'` property, when the state is mixed, we must explicitly set `aria-checked="mixed"` so screen readers correctly identify it as a partially checked state. The base `Toggle` checkbox logic only initialized `aria-checked` to a boolean.
**Action:** Always ensure that tri-state or indeterminate checkboxes explicitly set `aria-checked="mixed"` on the DOM node that receives keyboard focus and has `role="checkbox"`. Overriding the initialization and `applyStyles` methods in the subclass to set this attribute ensures screen readers correctly interpret all three states.
