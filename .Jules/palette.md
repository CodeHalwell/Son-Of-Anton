## 2024-05-18 - Stable Aria Labels for Dynamic Toggles
**Learning:** Toggle buttons with generic visual text that changes dynamically (e.g., switching between 'show' and 'hide') need a stable, descriptive `aria-label` (e.g., 'Toggle Extension Data'). The `aria-label` overrides the visible text content for screen readers, providing consistent context regardless of the current visual state.
**Action:** Always assign a stable, descriptive `aria-label` to toggle buttons with generic or dynamically changing text to ensure screen readers announce the accurate purpose of the button.
