## 2023-10-24 - Initial ARIA state and TS parameter properties
**Learning:** When creating accessible components, be aware that TypeScript parameter properties (like `private _state`) are initialized *after* `super()` is called. If the base class calls initialization methods like `applyStyles()` in its constructor, those methods will see the parameter property as `undefined`. For things like `TriStateCheckbox`, this means the initial DOM attributes like `aria-checked="mixed"` might not be applied by `applyStyles()` on initial load, leaving screen readers with an incorrect default state (like "unchecked").
**Action:** When extending base classes that call lifecycle methods in their constructors, explicitly set the initial ARIA attributes on the DOM node immediately *after* the `super()` call if those attributes depend on parameter properties.
