## 2024-05-15 - ARIA Labels for Icon/Interactive Text Buttons\n**Learning:** When using custom text elements or links as buttons (with `role="button"` and `tabIndex=0`) in Son of Anton, assigning them a localized `aria-label` provides a consistent screen reader experience, especially for toggles (like "show"/"hide") where the visual text changes dynamically.\n**Action:** Add `aria-label` to custom toggle buttons with generic text ("show", "hide") using localized strings that describe the element's context, not just its current visual state.
